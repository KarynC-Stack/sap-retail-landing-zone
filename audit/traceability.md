# Generic audit traceability

| Control objective | Framework element | Expected private evidence |
| --- | --- | --- |
| Governance changes are authorized | Opt-in organization foundation | Approved change record and reviewer decision |
| Configuration is reviewed | Placeholder sample configuration | Private peer-review record |
| Templates are validated before use | Local and CI validation workflow | Validation job result retained with change |
| Operational roles are separated | Conceptual architecture boundaries | Approved responsibility matrix |
| Deployment records are retained | Private deployment boundary | Controlled deployment and rollback record |

This mapping is generic. It does not assert compliance, identify systems, or contain operational evidence.
